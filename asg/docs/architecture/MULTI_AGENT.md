# Logical agents

The orchestrator shares one local inference service with Requirements, Architect, Explorer, Developer, Testing, Debugging, Reviewer, Documentation and Maintenance roles. Each role has independent instructions, task context, tool grants and budget. Support reusable custom roles with the same constraints. Child task cancellation and bounded worktree ownership apply independently of model scheduling.

See the [canonical requirements](../REQUIREMENTS.md#coding-engine-development-phase) for priority, dependencies and acceptance.
